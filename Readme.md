
# Rinterio - Interior Design Website

Welcome to the **Rinterio** project! This is a responsive interior design website that showcases beautiful designs, offers customization options, and facilitates contact with the design team. The website is designed with a modern, user-friendly interface, allowing visitors to explore various services, portfolios, and ways to get in touch with our experts.

## Project Overview

Rinterio is a platform dedicated to interior design. It highlights various designer projects, offers users the ability to customize their own spaces, and allows them to get in touch with our design team through virtual appointments, in-person consultations, or direct chat.

### Key Sections:
- **Designer Showcase**: Showcasing beautiful designs with information about each project.
- **Customization Options**: Offering virtual and in-person consultation bookings, as well as an online chat for questions.
- **Next Project Section**: Users can contact the design team for upcoming projects with a detailed form.
- **Footer**: Includes navigation links and a call-to-action to book a consultation.

## Features

- Responsive design using Tailwind CSS for a modern and adaptable layout.
- **Designer Showcase**: Cards featuring various interior design projects with images and descriptive details.
- **Customization Options**: Users can book virtual or in-person appointments and chat with a design expert.
- **Contact Form**: A section to discuss the next project and submit inquiries.
- **Footer**: Includes navigation links to various sections like Home, Services, Portfolio, Blogs, and Contact Us.

## Installation

Follow the steps below to get the project up and running on your local machine.

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/rinterio.git
   ```

2. Navigate into the project directory:
   ```bash
   cd rinterio
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:3000` to view the website.

## Usage

The website is divided into several sections for easy navigation:
- **Designer Showcase**: Explore various designs by clicking on the "Let’s Check" button.
- **Customization Section**: Book a virtual or in-person consultation or start a chat with an expert.
- **Next Project Section**: Fill out the contact form to discuss the next interior design project.
- **Footer**: Access the main navigation and book a consultation with the team.
